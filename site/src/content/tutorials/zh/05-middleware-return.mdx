模型可能提出“搜索三种方案、写报告”，也可能说“请先明确比较范围”。工具调用需要经过检查才能执行。**middleware 决定哪些调用能执行，工具结果怎样被记录，以及何时停止继续调用模型。**

这里有三个不同边界：`after_model` 处理模型响应；`wrap_tool_call` 包住工具；`after_agent` 处理正常的图结束。worker 还要承担异常、取消与最终落盘，不能将正常 hook 当成所有路径的 finally。

## after_model：先决定下一步是否成立

<SourceRef file="backend/packages/harness/deerflow/agents/lead_agent/agent.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="build_middlewares" /> 将 Clarification 放在内置链末端，SafetyFinishReason、ModelLengthFinishReason 等终止处理靠近它。after hook 逆序执行，因此安全终止检查可以在后续用量归因与控制逻辑消费响应前清除不应执行的调用。extension 合成还要遵守宿主顺序约束。

| 情况 | 处理意图 | 不能误解成 |
| --- | --- | --- |
| 请求澄清 | 将问题交回用户，结束当前执行分支 | 后台工具一直阻塞等人回复 |
| provider 安全终止 | 识别安全停止并抑制不可信 tool calls | 自动重试，直到绕过 provider 限制 |
| 输出长度上限 | 标记长度终止，避免执行不完整动作 | 等同于任务已经完成 |
| 委派超限 | 限制并行调用与本次总量 | 自动替模型规划任务 |
| 循环或 token 预算达到阈值 | 告警、限制继续调用或促使结束 | 保证报告业务验收通过 |

<SourceRef file="backend/packages/harness/deerflow/agents/middlewares/clarification_middleware.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="ClarificationMiddleware" /> 拦截 `ask_clarification` 并形成可展示的消息和控制流更新；非交互运行则有另一套策略。<SourceRef file="backend/packages/harness/deerflow/agents/middlewares/safety_finish_reason_middleware.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" /> 还覆盖当前 provider 返回的安全终止形态，不能只看单个字符串字段。

TokenBudget 是可配置的 run 预算机制。它依赖可用 usage 计数，可能在调用结束后发现已越过阈值；不是 provider 账单的精确预扣款。

## receipt 证明调用关联，不证明结论正确

<SourceRef file="backend/packages/harness/deerflow/agents/middlewares/tool_receipt_middleware.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="ToolReceiptMiddleware" /> 为返回的 ToolMessage 或 Command 中的对应消息附加运行凭据，并覆盖工具自行伪造的同名字段。它位于这些可提前返回的策略层外侧，使“被拒绝”“执行出错”也有记录。

子 agent 报告可以引用 receipts；lead 可以核验引用是否指向真实调用及其状态。**一张成功读取文件的 receipt，只能支持“发生了这次读取”，不能证明文件内容真实、引用解释正确或研究充分。**

工具异常由 <SourceRef file="backend/packages/harness/deerflow/agents/middlewares/tool_error_handling_middleware.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="ToolErrorHandlingMiddleware" /> 规范化，结果元数据为进度、验收和审计提供结构信息。业务错误、策略拒绝、真实取消仍需各自保留语义。

## 大结果、artifact 与报告文件

<SourceRef file="backend/packages/harness/deerflow/agents/middlewares/tool_output_budget_middleware.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="ToolOutputBudgetMiddleware" /> 将超大结果持久化并用有类型的摘要和文件引用代替；持久化不可用时有有界降级路径。对于已经被后续成功读写取代的历史 `write_file.content`，还可以只在模型请求视图里缩减参数，保留原始 state、checkpoint 和凭据。

<SourceRef file="backend/packages/harness/deerflow/agents/middlewares/artifact_capture_middleware.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="ArtifactCaptureMiddleware" /> 的捕获发生在下一轮 `before_model`，不是在工具 wrapper 中把每个返回值再包一层 Command。它从结果中提取产物引用，维护 `tool_artifacts`，供后续 handle 使用。

报告交付涉及几个独立步骤：

~~~text
write_file 成功：文件已写入执行环境
artifact 元数据：运行时知道有这个引用
present_files：将产物交给用户展示
用户可下载：还依赖文件实际存在、路径授权和存储可达
~~~

核对交付结果时，需要沿着文件写入、引用登记、界面展示和下载访问逐层检查。

## after_agent 与 worker：两层收尾

正常 graph 结束时，middleware 可以生成标题、提交记忆更新、释放 sandbox execution lease。记忆写回由 agent 配置、memory 模式和所选 backend 共同决定。

<SourceRef file="backend/packages/harness/deerflow/sandbox/middleware.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="SandboxMiddleware" /> 释放本次执行的资源占用。多个子执行共享 sandbox 时，一次 release 不应立刻销毁别人仍在使用的资源。

<SourceRef file="backend/packages/harness/deerflow/runtime/runs/worker.py" sha="51d59a1cdff92626bd9f03f1b2254f34a824ca3e" symbol="run_agent" /> 再协调事件写入、完成信息、终态、取消清理和流结束。HTTP 收到最后一个 token，不代表所有持久化步骤已完成；反过来，图已终止也不保证外部工具副作用能被撤销。

<Philosophy>
可靠的 agent 需要保留“提出动作、允许执行、发生结果、验收交付”的差别。middleware 将这些边界放进真实执行路径，receipt 和事件让它们可检查，但最终任务质量仍要回到来源与验收条件。
</Philosophy>
